# Changelog

## v5.3 — 2026-09-06

首个建议长期保留的稳定版本。

### 交互

- 全中文一键向导；
- 单次运行可连续迁移多个仓库；
- 下一仓库可复用上一组 PAT；
- 每个仓库完成后明确显示成功仓库名；
- 终端只展示与用户决策相关的信息，详细技术输出进入日志。

### 安全与一致性

- 目标 Actions 在迁移期间保持关闭；
- 最终冻结源仓库后执行 Git/LFS final sync；
- branches/tags 做最终一致性校验；
- 默认分支升级为硬校验；
- Secret 只迁移名称并要求目标重新填写；
- Unknown 状态不再被误判为 Empty；
- Actions 恢复失败时按 fail-safe 尽力重新关闭。

### 报告准确性

- 区分“确认存在但未迁移”“状态无法确认”“功能/套餐不适用”；
- Free 私有个人仓库的 Rulesets 404 不再误报为风险；
- Release、Wiki、Pages、Webhook、Deploy key、保护规则等真实差异会明确点名；
- Repository metadata 与 Topics 根据最终实际状态判断，而不是仅根据 API 请求是否成功判断。

### 兼容性

- 兼容 macOS 自带 Bash 3.2；
- 修正中文多字节环境下变量展开相关兼容问题；
- 单仓库执行隔离，单个仓库异常不会静默击穿批量主循环。
