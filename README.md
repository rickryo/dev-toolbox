# dev-toolbox

一组不值得单独建立仓库、但值得长期保留和维护的小型开发 / 运维工具。

## 组织方式

- 一个工具一个独立子目录。
- 每个工具目录至少包含：
  - 可直接执行或使用的工具文件；
  - `README.md`：用途、前置环境、安装依赖、授权/初始化命令、使用方式、边界与注意事项。
- 工具主文件使用稳定文件名，不在文件名中堆叠版本号；版本记录放在工具内部和 `CHANGELOG.md`。
- 临时状态、迁移日志、缓存等运行产物不提交到仓库。

## 新增工具约定

新增工具时，建议目录结构保持简单：

```text
tool-name/
├── README.md
├── CHANGELOG.md        # 有版本演进时保留
└── tool-file           # 脚本、程序或其他主文件
```

README 优先回答四件事：

1. 这个工具解决什么问题；
2. 运行前需要安装什么；
3. 第一次执行前需要做什么初始化/授权；
4. 最短运行命令是什么。
